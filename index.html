01 / Foundations

Four disciplines.
One engineering stack.

Each discipline widens the scope. Loops are one important part of the harness around the model.

From inner to outer
HARNESS ENGINEERINGRuntime, tools, memory, skills, filesystem, loops
CONTEXT ENGINEERINGRight information, at the right time
PROMPT ENGINEERINGThe instructions
Agents are non-deterministic: the same code and input can behave differently. Understand behavior from traces—not code alone.
✎

Prompt engineering

Optimize the instructions sent to a model. It is only one part of the context.

▤

Context engineering

Make sure the right information reaches the LLM at the right time.

⌘

Harness engineering

Design the systems around the model: filesystems, interpreters, sandboxes, instructions and memory.

↻

Loop engineering

Build feedback loops around an agent to make it more reliable and improve over time.
